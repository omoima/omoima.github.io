# omoima.github.io — Oraaabz

Personal GitHub Pages site for Oarabile Moima (@oraaabz). A tiny custom static
site generator written in Python — no Jekyll, no Hugo, just `builder.py`.

## How it works

The whole pipeline is one script, `builder.py` (~100 lines):

1. Reads Markdown files with YAML frontmatter (`title`, `date`, etc.) using
   `python-frontmatter`, converts the body to HTML with `markdown`
   (extensions: `fenced_code`, `codehilite` for Pygments syntax highlighting).
2. Renders each post through the Jinja2 templates in `templates/`
   (`base.html` → `post.html` / `index.html`).
3. Wipes and regenerates `public/` on every build:
   - `content/posts/*.md` → `public/posts/<name>.html`
   - `content/pages/*.md` → `public/<name>.html` (uses `page.html` if it
     exists, otherwise falls back to `post.html` — currently only the fallback
     exists)
   - Index page lists all posts, sorted reverse-chronologically by `date`
   - `static/` is copied to `public/static/`
4. Posts without a `title` in frontmatter default to "Oraaabz".

## Layout

- `builder.py` — the entire site generator
- `content/posts/` — blog posts (Markdown + frontmatter)
- `content/pages/` — standalone pages, e.g. `about.md`
- `templates/` — Jinja2: `base.html`, `index.html`, `post.html`
- `static/css/style.css` — site styling (light theme, gold accents,
  Caribbean blue highlights)
- `public/` — generated output; committed, but fully regenerated by builds.
  Never edit by hand.
- `tests/test_builder.py` — pytest suite for parsing, templating, and a full
  build against a temp dir

## Commands

```bash
source .venv/bin/activate        # venv lives at .venv/
pip install -r requirements.txt
python builder.py                # build → public/
python -m http.server 8000 --directory public   # local preview
PYTHONPATH=. pytest              # run tests
```

## Deployment

`.github/workflows/deploy.yml` runs on every push to `main`:
install deps → `pytest` → `python builder.py` → upload `public/` as a
Pages artifact → deploy via `actions/deploy-pages`. Tests failing blocks
the deploy.

## Conventions

- To add a post: drop a `.md` file in `content/posts/` with `title` and
  `date` frontmatter, then push to `main` — CI builds and deploys.
- The `date` frontmatter drives index ordering; posts without one sort last.
- Owner enjoys Python and PyCharm; keep the toolchain plain Python.
